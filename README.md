# StudySnap ⚡

Aplicação web que gera flashcards de estudo automaticamente usando IA.

## 🔗 Demo
[study-snap-weld.vercel.app](https://study-snap-weld.vercel.app)

## 🚀 Tecnologias
- Next.js 14 + TypeScript
- Tailwind CSS
- API do Claude (Anthropic)
- Supabase (banco de dados + autenticação)
- Vercel (deploy)

## ✨ Funcionalidades
- Cola um texto e a IA gera 5 flashcards automaticamente
- Login com Google
- Salva e gerencia seus decks de flashcards
- Interface responsiva

## 🛠️ Como rodar localmente
1. Clone o repositório
2. Instale as dependências: `npm install`
3. Configure o `.env.local` com as variáveis de ambiente
4. Rode: `npm run dev`
